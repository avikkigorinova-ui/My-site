Четыре паттерна на одном наборе данных

Данные загружаются из data.json через fetch. Запустите страницу через локальный веб-сервер.

1. Observer (Наблюдатель)

При выборе книги обновляются карточка, счётчик просмотров и журнал. Обработчик меняет состояние, а блоки подписаны на его изменение.

Просмотров: 0

Журнал Observer

2. Strategy (Стратегия)

Переключатель меняет способ сортировки. Каждый способ — отдельная функция, подставляемая во время работы.

    3. Command (Команда)

    Добавление и удаление книги оформлены командами с execute() и undo(). Кнопка «Отменить» откатывает последнее действие.

      Журнал команд

      4. Singleton (Одиночка)

      Общий журнал действий — единственный экземпляр. Разные части страницы обращаются к одному объекту.

      Нажмите кнопку, чтобы сравнить два вызова ActionLog.getInstance().
